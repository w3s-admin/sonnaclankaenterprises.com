# Quick Reference: "How Do I...?"

A cheat-sheet for common tasks. For full explanations, see the linked guide.

| I want to... | Where to go |
|---|---|
| Put a new car up for sale | Admin Panel → **Vehicle → Add Vehicle** ([details](03-managing-vehicles.md)) |
| Find/edit/search my current stock | Admin Panel → **Vehicle → Vehicle Manager** |
| Mark a car as sold | Admin Panel → **Vehicle Manager** → find the car → mark sold |
| Get a printable list of unsold cars | Admin Panel → **Vehicle → Unslod List** |
| Add a customer testimonial | Admin Panel → **Review → Add Review** ([details](04-managing-reviews.md)) |
| Edit or remove a testimonial | Admin Panel → **Review → Review Manager** |
| Give a staff member their own login | Admin Panel → **User → Add User** ([details](05-staff-accounts.md)) |
| See who has admin access | Admin Panel → **User → User Manager** |
| Log into the admin panel | Go to `sonnaclankaenterprises.com/systemadmin/` ([details](02-the-admin-panel.md)) |
| Check what a customer submitted through the Contact form | Check your email inbox at `info@sonnaclankaenterprises.com` — submissions arrive there directly, no login needed |
| See what customers can do on the website | [The Public Website](01-the-public-website.md) |
| Understand the newsletter/email feature (currently off) | [Newsletter & Email Tools](06-newsletter-emails.md) |

## The Golden Rule

**Anything you change in the admin panel shows up on the live public website immediately.** There's no "draft" mode, no approval step, and no undo button beyond editing it back — so it's worth double-checking details (price, spelling, photos) before saving, especially for a vehicle listing that real customers will see right away.
