# Newsletter & Email Tools

## Important: This Feature Isn't Currently Turned On

Unlike everything else in this guide, the newsletter tools **don't have a button or menu link anywhere in the admin panel**. The pages exist and work if you visit them directly, but there's currently no way to *discover* them just by clicking around — you'd need to know the exact page name to reach them.

This is worth knowing about even though it's not active, because the pieces are already built and could be switched on (by adding a menu link) whenever you want to start using it.

## What It Does, When Used

The idea is: customers can subscribe to your newsletter from the **sign-up box in the website footer**. Their email gets stored in a subscriber list. From the admin side, you'd then be able to:

1. **Manage your subscriber list** — see everyone who's signed up, search/add/remove emails.
2. **Pick which vehicles to feature** — choose specific cars from your stock to highlight in an email.
3. **Compose and send a newsletter** — write a subject line and message, then send it out to your selected subscribers in one go. The default subject line is something like *"Vehicle Stock List Update"* with today's date, suggesting it's meant for "here's what's new in stock" style emails.

## Should You Turn It On?

That's your call. A few things worth considering first:
- It sends **real emails** to everyone on the subscriber list when you hit send — there's no "preview only" safety net described in what's there, so it's worth testing carefully with a small list first.
- Since it wasn't part of the main flow that's been actively tested and polished this session, it's worth a careful test run before relying on it for real customer communication.

If and when you want this switched on (a visible menu link added, tested end-to-end), that's a small, well-defined follow-up task.
