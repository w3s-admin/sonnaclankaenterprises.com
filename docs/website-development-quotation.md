## 1. Project Overview

A two-sided vehicle dealership platform:

- **Public website** — customers browse and search vehicle stock, view full vehicle details, read testimonials, and contact the dealership (call, WhatsApp, form) — no account or login required.
- **Admin panel** — a password-protected back office for staff to manage vehicle inventory, customer reviews, and staff accounts, with changes reflected on the live site instantly.

---

## 2. Scope of Work & Features

### 2.1 Public Website

| Feature | Description |
|---|---|
| Homepage | Welcome banner with live "cars in stock" counter, spotlighted vehicle, quick Make/Model/Body-Type search, New Arrivals showcase, "Why Choose Us" trust section, call-to-action banner, testimonials |
| Vehicle Listing / Stock Page | Full inventory browsing with filters (Make, Model, Body Type, Transmission, keyword, reference number) |
| New Vehicles Page | Dedicated browsing view for newest stock |
| Vehicle Detail Page | Photo gallery, full specifications, pricing, Call Now + WhatsApp buttons, embedded location map |
| About Page | Company history, key stats, testimonials |
| Contact Page | Contact form (emails directly to business inbox), address/phone/hours, embedded map |
| Floating WhatsApp Button | Persistent click-to-chat button on every page, pre-filled message |
| Newsletter Sign-Up (footer) | Email capture widget feeding the subscriber list |
| Responsive Design | Fully usable on desktop, tablet, and mobile |

### 2.2 Admin Panel — Core

| Feature | Description |
|---|---|
| Secure Login | Username/password authentication, session logout |
| Dashboard | Landing page after login with sidebar navigation |
| Sidebar Navigation | Organized into User / Vehicle / Review sections |

### 2.3 Vehicle Management Module

| Feature | Description |
|---|---|
| Add Vehicle | Full intake form — identification, specs, pricing (incl. "Highest Offer" & Special Offer price), 17+ feature checkboxes, free-text options, multi-photo upload |
| Vehicle Manager | Searchable/filterable master inventory list (by stock, category, body type, colour, make, model, transmission, chassis no., keyword, reference no.) |
| Edit Vehicle | Pre-filled edit form, live-updates the public site immediately |
| Mark as Sold | Records sale price, removes from public listings, moves to sold history |
| Unsold List Report | Printable pop-up report of current unsold stock |

### 2.4 Customer Reviews Module

| Feature | Description |
|---|---|
| Add Review | Name, title, country, comment, optional photo (auto-generated initial badge if no photo) |
| Review Manager | Edit, delete, and toggle active/inactive status |
| Live Sync | Active reviews appear on both Homepage and About Page automatically |

### 2.5 Staff Accounts Module

| Feature | Description |
|---|---|
| Add User | Staff login creation — name, username, password, email, contact number, notes |
| Super Admin Toggle | Full-access vs. restricted-access account designation |
| User Manager | Edit/remove staff logins |

### 2.6 Newsletter & Email Tool

| Feature | Description |
|---|---|
| Subscriber List Management | View, search, add, remove subscribers |
| Vehicle Feature Selection | Pick specific stock items to highlight in an email |
| Compose & Send | Subject line + message composer, bulk send to selected subscribers |
